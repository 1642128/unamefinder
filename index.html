How to host your Pr0xy Node server on GitHub Codespaces
  1. Create a new public/private repository on GitHub and launch a free Codespace.
  2. Create a file server.js with Express & Node fetch pr0xy routing.
  3. Run npm init -y && npm install express cors node-fetch @mercuryworkshop/wisp-js
  4. Start the server with node server.js on port 8080.
  5. In Codespaces, navigate to the Ports Tab, right-click Port 8080, and change Port Visibility from Private to Public.
  6. Paste your public Codespace domain URL into the MineSeek Pr0xy settings above!
